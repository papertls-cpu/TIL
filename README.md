add, commit, push
add 저장 commit 기록 push 이력
git add . - 전체 파일 add
git add 파일명.확장자 - 원하는 파일만

git은 작성하고 확인할때 사용자 설정을 해야함 
git config --global user.name "이름"
git config --global user.email "이메일"
--local  --global  --system 순으로 커짐. 로컬은 그 폴더 하나만, 글로벌은 이 컴퓨터 유저, 시스템은 이 컴퓨터 쓰는 사람
.gitignore는 깃이 무시해야하는 파일 정리

git log (git 기록 조회)
예시 : git commit -m "d0fb6d 로그인 기록 수정"
git status
git remote add origin https://github.com/papertls-cpu/first.git

git commit 버전 되돌리기
git reset --hard head 그냥 되돌림
git revert head 커밋 메세지 남기고 되돌림
git restore --staged 파일 add 된 파일에서 하나만 빼기

git clone [URL] - 처음에 한번만
git pull - 이후 업데이트 따라갈때

조사할 키워드: config system, local, global이 뭔지, branch가 뭔지, .gitignore가 뭔지
